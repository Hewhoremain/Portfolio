What I do

Evidence first, then conclusions. My reports hold up because every finding traces back to an artifact.

I run forensic investigations end to end: imaging, memory and disk analysis, malware analysis, root cause analysis and log correlation. I also build the defenses that follow: detection engineering, SOAR playbooks, endpoint hardening and security tool integration across SIEM, EDR and NDR platforms.

Case studies

Real investigations, anonymized. Client names and identifying details are left out. Tap a case to read it.

Qilin ransomware: tracing the intrusion through ESXiRansomware incident response

What happened

A Qilin ransomware attack hit the environment. The questions were how the attacker got in, and which ESXi servers they had compromised.

What I did

I worked through the forensic artifacts to find the entry point and identify the affected ESXi servers, then pulled indicators of compromise (IOCs) from those artifacts.

Result

The IOCs were used to protect the rest of the infrastructure, which helped stop the attack from spreading.

The unwanted program that turned a laptop into a relayEndpoint investigation, potentially unwanted program (PUP)

What happened

A PUP had been installed on an employee's laptop and the security tools had not detected it.

What I found

The program was using the user's network bandwidth to route other people's traffic. Some of that routed traffic was also trying to reach the company's website.

Threat hunt on an on-premises network: executables no tool had flaggedThreat hunting

What I found

A hunt across an on-premises environment turned up an executable present on systems that no security tool had detected. I also found registry changes and several Impacket tools that the threat actor had used.

Insider data theft: following the trail on a laptopInsider threat, Windows forensics

What happened

An internal user transferred confidential data to a third party and to himself, then deleted the traces.

What I did

Using Windows forensics on the employee's laptop, I worked out which files and data he had touched and which channel he used to send them out.

Business email compromise: how far did the email spread?BEC investigation, Microsoft 365

What I checked

The compromised inbox and its forwarding rules, plus email header analysis. I then reviewed Microsoft logs, Graph API logs and other logs.

What I answered

How many other business users received the same email, and which of them clicked on it.

Making the SOC quieter and closing coverage gapsSOC engineering and vulnerability assessment

What I did

Result

Reduced the gaps in coverage across endpoints and servers.
